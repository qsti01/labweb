# FitnessApp — WordPress Theme & Docker Environment (Лабораторная работа 5)

Интеграция верстки адаптивного лендинга FitnessApp (из лабораторной работы 3/4) в систему управления сайтом (CMS) WordPress с поддержкой Docker-развертывания и сбора заявок в базу данных.

---

## 1. Доступ к локальному сайту (Docker)

Контейнеры запускаются через Docker Compose:
```bash
cd lab5
docker compose up -d
```

- **Сайт:** [http://localhost:8088](http://localhost:8088)
- **Панель администрирования WordPress:** [http://localhost:8088/wp-admin](http://localhost:8088/wp-admin)
- **Веб-интерфейс phpMyAdmin:** [http://localhost:8081](http://localhost:8081)
  - Сервер: `db`
  - Пользователь: `wordpress`
  - Пароль: `wordpress_password`

```text

│           ├── index.php       # Основной шаблон блога/архива (Fallback)
```

## 3. Выполненные требования задания

### 3.1. Редактирование страниц в WYSIWYG-редакторе
- Шаблон `page.php` позволяет создавать любые внутренние страницы в визуальном редакторе WordPress.
- Заголовки, списки, цитаты, таблицы и кнопки оформлены в едином фирменном стиле FitnessApp.
- В шаблон `front-page.php` встроен блок вывода контента, если на главной странице администратор решит добавить произвольный текст/блоки через редактор.

### 3.2. Управление пунктами меню через «Админку»
- Меню управляется стандартным способом в разделе **Внешний вид -> Меню**.
- В `functions.php` зарегистрирована область меню через `register_nav_menus()`, а в `header.php` выводится через `wp_nav_menu()`.

### 3.3. Сбор и отображение заявок с формы
- Email-адреса из форм лендинга автоматически сохраняются в базу данных (`wp_fitnessapp_leads`).
- В админке WordPress в разделе **«Заявки»** отображается простой список полученных email, источника (Hero или Connect) и даты.
